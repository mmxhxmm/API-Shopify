# API-Shopify
A simple API that connects your Shopify store with Google Sheets.
Easily fetch sales data from Shopify using GraphQL and export it into a structured Google Sheet.

Features
Fetch sales/order data directly from your Shopify store

Automatically sync data to a new or existing Google Sheet

Customize the date range and number of orders to retrieve

Based on Shopify's GraphQL Admin API

Minimal configuration and easy to use

How It Works
The API uses a GraphQL query to retrieve order data from your Shopify store.

It authenticates and connects to the Google Sheets API.

The retrieved data is written into a Google Sheet.

Users can customize requests by specifying a date range and number of orders.
