<h1><b>API-Shopify</b></h1>

  <p>
    A simple API that connects your Shopify store with Google Sheets.<br>
    Easily fetch sales data from Shopify using GraphQL and export it into a structured Google Sheet.
  </p>

  <h2><b>Features</b></h2>
  <ul>
    <li>Fetch sales/order data directly from your Shopify store</li>
    <li>Automatically sync data to a new or existing Google Sheet</li>
    <li>Customize the date range and number of orders to retrieve</li>
    <li>Based on Shopify's GraphQL Admin API</li>
    <li>Minimal configuration and easy to use</li>
  </ul>

  <h2><b>How It Works</b></h2>
  <ol>
    <li>The API uses a GraphQL query to retrieve order data from your Shopify store.</li>
    <li>It authenticates and connects to the Google Sheets API.</li>
    <li>The retrieved data is written into a Google Sheet.</li>
    <li>Users can customize requests by specifying a date range and number of orders.</li>
  </ol>
